questions

Three questions most founders cannot answer

About their own company, today. d7r sweep answers the first read-only in one command; the rest of the suite gives a structure for answering the other two.

01

What is installed?

see

Which AI coding tools are running inside the company.

Agents, harnesses, IDE plugins, MCP servers: an inventory taken from the machines themselves, not from the procurement list.

02

What can it read?

govern

What those tools are allowed to touch.

Repository access, file scopes, environment secrets, network reach: the permissions as they are, against the permissions as intended.

03

Where do transcripts go?

report

Where the record of everything they read ends up.

Session logs, telemetry, cloud retention: the evidence trail of the tooling itself, reported in language a board can act on.

toolkit

One product line, three surfaces

01

The tools

cli

The d7r binary and its detector catalog.

A Rust core for detection, redaction, and evidence; official plugins for coding agents and harnesses; adapters for log sinks, compliance platforms, and security tools. Read-only by design.

02

The audit packet

practice

The Fractional CTO packet: steering, scaffolds, templates, examples.

The working documents of an engagement, branded under the Academy document kit (forest and gold, severity ledgers, evidence-first reporting), so a finding arrives as something a founder can act on.

03

The courses

academy

Course material distributed with the tools.

The D7R Frontier Academy curriculum teaches the practice the tools instrument: how to see, govern, and report on AI tooling as the CTO the company doesn't have yet.

constraints

What these tools will never do

Constraints on the design, not a roadmap.

CommitmentWhat it means
Observe, never remediateNo command changes the system under audit.
No account, no network, no phone homeEvery core command completes offline.
Credentials excluded by constructionNot filtered out afterwards.
"Unknown" is a legal answerRecorded with its reason. Guessing destroys a re-audit product.
No compliance claimEvidence-backed recommendations. No badge, no pass mark, no certification.
No scoring of peopleThe unit of analysis is a system, a repository, or a harness; never a developer's output.
